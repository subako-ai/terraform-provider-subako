## Write only from public information

This repository is public: code, comments, documents, commit messages, and
pull request descriptions are read by anyone. Write them from what a provider
user can see -- the Subako API, the document it publishes at `/openapi.json`,
its schema names (`AgentConfigBody`), its behavior, and this repository
itself -- and nothing else.

Describe a change by what the provider does after it, not by why or when
anything outside this repository changed.
